# 10 张图逐张操作配方（Power BI Desktop）

> 适用：已导入 `monthly_kpis_zh`、`category_kpis_zh`、`payment_type_kpis_zh`、`state_kpis_zh`、`cohort_retention_zh`，并补导入 `seller_kpis_zh`、`delivery_distribution_zh`。
>
> 字段名说明：当前模型里月份列可能叫 **`年月文本`**（截图里是这个名字）；如果配方写的是 `月份`，请替换成你实际的列名。DAX 度量值不依赖月份列，不需要改。
>
> 视觉对象名称以中文版 Power BI Desktop 为准；英文版对应名称在括号里。

## 图 1｜月度 GMV 与有效订单（双轴组合图）

**视觉对象**：折线和簇状柱形图（Line and clustered column chart）

| 字段井 | 放什么 |
|---|---|
| X 轴 | `月份`（或 `年月文本`） |
| 列 Y 轴 | `商品GMV` |
| 行 Y 轴 | `有效订单数` |
| 工具提示 | `核心_客单价`、`核心_迟到率`、`核心_平均评论分` |

**步骤**

1. 选中空白画布 → 视觉对象 → 折线和簇状柱形图。
2. 按上表拖字段。
3. 格式 → Y 轴 → 打开「次坐标轴」；列轴单位百万，行轴单位千。
4. 格式 → 数据颜色：柱 `#1F4E79`，线 `#F4A261`；线宽 2.5，打开标记。
5. 如果 X 轴按字母乱序：
   - 新建计算列 `月份排序`：
     `月份排序 = VALUE(LEFT([年月文本],4))*100 + VALUE(MID([年月文本],6,2))`
   - 选中 `年月文本` → 列工具 → 按列排序 → `月份排序`。
6. 标题写「月度 GMV 与有效订单：2017-11 为峰值」，脚注写数据来源。
7. 保存。

## 图 2｜品类 GMV Top 10（横向条形图）

**视觉对象**：簇状条形图（Clustered bar chart）

| 字段井 | 放什么 |
|---|---|
| Y 轴 | `品类` |
| X 轴 | `商品GMV` |
| 工具提示 | `GMV占比`、`有效订单数`、`评论分`、`迟到率` |

**步骤**

1. 拖入视觉对象和字段。
2. 视觉对象筛选器 → `品类` → 筛选类型「Top N」→ 显示前 10 项 → 按 `商品GMV` 降序。
3. 视觉对象右上角 → 排序 → 按 `商品GMV` 降序；检查横向条形图方向。
4. 格式 → 数据标签 → 打开；显示单位「百万」或自定义 `R$#,##0.00`。
5. 颜色：深蓝 → 浅蓝渐变；条形圆角 2px。
6. 标题「品类 GMV Top 10：美妆个护第一」。

> Top N 必须做在**视觉对象筛选器**，不要用 DAX 过滤表。

## 图 3｜支付金额构成（环形图）

**视觉对象**：环形图（Donut chart）

| 字段井 | 放什么 |
|---|---|
| 图例 | `支付方式` |
| 值 | `支付金额` |
| 工具提示 | `支付金额占比`、`订单数` |

**步骤**

1. 拖入环形图：图例 `支付方式`，值 `支付金额`。
2. 格式 → 详细信息标签 → 打开，标签内容选「类别、百分比」，小数位 1。
3. 格式 → 环 → 内径 65%–70%；图例放右侧。
4. 需要中心总额时：插入 → 卡片图，值放 `核心_支付金额`，背景透明，叠在环形图中心。
5. 标题「支付金额构成：信用卡约 78.5%」。
6. **不要用订单占比画饼图**：一笔订单可能同时有信用卡+代金券，订单占比相加会超过 100%。

## 图 4｜品类规模、评分与迟到率（气泡散点图）

**视觉对象**：散点图（Scatter chart）

| 字段井 | 放什么 |
|---|---|
| X 轴 | `商品GMV` |
| Y 轴 | `评论分` |
| 大小 | `有效订单数` |
| 详细信息 | `品类` |
| 图例 | `迟到率分组`（计算列） |
| 工具提示 | `GMV占比`、`迟到率`、`有效订单数` |

**先建计算列**（在 `category_kpis_zh` 表上，右键 → 新建列）：

```DAX
迟到率分组 =
SWITCH (
    TRUE (),
    'category_kpis_zh'[迟到率] < 0.05, "低于5%",
    'category_kpis_zh'[迟到率] < 0.08, "5%-8%",
    'category_kpis_zh'[迟到率] < 0.11, "8%-11%",
    "11%以上"
)
```

**步骤**

1. 拖入散点图，按上表放字段。
2. 视觉对象筛选器 → `有效订单数` ≥ 30，去掉长尾。
3. 格式 → X 轴 → 对数刻度；Y 轴范围 3.6–4.8。
4. 分析窗格 → 添加中位数线（X、Y 各一条），灰色虚线。
5. 原生散点图不支持连续颜色渐变，所以用 `迟到率分组` 图例表达颜色；tooltip 里保留具体 `迟到率`。
6. 标题「品类规模、评分与履约：气泡=订单量，颜色=迟到率」。

## 图 5｜州级 GMV 与迟到率（地理气泡图）

**视觉对象**：地图（Map）；如果只需要填色，用「着色地图」（Filled map）

| 字段井 | 放什么 |
|---|---|
| 位置 | `州` |
| 纬度 | `客户纬度` |
| 经度 | `客户经度` |
| 大小 | `商品GMV` |
| 颜色饱和度 | `迟到率` |
| 工具提示 | `有效订单数`、`准时率`、`平均送达天数` |

**步骤**

1. 拖入「地图」视觉对象。
2. 位置放 `州`；纬度/经度分别放 `客户纬度`、`客户经度`。
3. 大小 `商品GMV`，颜色饱和度 `迟到率`。
4. 建模 → 选中 `州` → 数据类别 → 州或省；如果地图不识别中文州名，优先用经纬度。
5. 如果视觉对象有「国家/地区」字段，新建列 `国家 = "巴西"` 放进去。
6. 格式 → 地图主题 → 浅色/灰度；气泡透明度 20%；颜色图例放右下。
7. 如果公司禁用 Bing 地图：改用「散点图」X=客户经度、Y=客户纬度、大小=商品GMV、图例=迟到率分组。

## 图 6｜送达天数分布（柱形图/直方图）

**视觉对象**：簇状柱形图（Clustered column chart）

| 字段井 | 放什么 |
|---|---|
| X 轴 | `送达时长区间` |
| Y 轴 | `订单数` |
| 工具提示 | `占比`、`迟到率`、`平均评论分` |

**步骤**

1. 拖入 `delivery_distribution_zh` 的 `送达时长区间` 和 `订单数`。
2. 新建排序用计算列：

```DAX
送达时长排序 =
SWITCH (
    'delivery_distribution_zh'[送达时长区间],
    "0-3天", 1, "4-7天", 2, "8-14天", 3,
    "15-21天", 4, "22-30天", 5, "31-60天", 6, "60天以上", 7
)
```

3. 选中 `送达时长区间` → 按列排序 → `送达时长排序`。
4. 格式 → 数据标签 → 打开；Y 轴单位千。
5. 标题「送达天数分布：集中在 8–15 天，长尾拖到 30 天以上」。
6. 如果要真正的逐单直方图，用 `orders_master_zh` 的 `送达天数` 按 0–3/4–7/…/60+ 分箱，再画柱形图；本包先用预聚合表，最快。

## 图 8｜Cohort 留存（矩阵热力图）

**视觉对象**：矩阵（Matrix）

**表**：`cohort_retention_zh`（长表，不用宽表，不用逆透视）

| 字段井 | 放什么 |
|---|---|
| 行 | `首购月份` |
| 列 | `距首购月数` |
| 值 | `Cohort_留存率`（或直接放 `留存率`，聚合选平均值） |

**步骤**

1. 拖入矩阵。
2. 行 `首购月份`，列 `距首购月数`，值 `留存率`。
3. 如果 Power BI 自动求和，改用度量值 `Cohort_留存率 = AVERAGE('cohort_retention_zh'[留存率])`。
4. 格式 → 值 → 背景色 → 条件格式 → 渐变：最小值 0 白色，最大值 0.008 深蓝。
5. 关闭小计；列宽调窄；字号 8。
6. 只保留 `距首购月数` 1–12（视觉筛选器），避免第 0 月 100% 把颜色压平。
7. 标题「Cohort 留存：首购后 1–12 个月」。

## 统一格式清单

- 金额：`R$ #,##0.00`；大额 KPI 可显示 `R$ 13.45M`。
- 比例：`0.0%`；不要先乘 100。
- 计数：`#,##0`；天数：`0.0`；评分：`0.00`。
- 标题写结论；脚注写「数据：report/tables_zh；口径见 analysis_guide.md」。
- 每张图加 Alt 文本（格式 → 常规 → 替代文本）。
- 图 1/2/3/4/5/6/8/9 可联动；图 7/10 是静态图，不联动。
