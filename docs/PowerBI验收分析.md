## 3. 需要处理的问题

### 3.1 两张静态图不能交互（优先级：高）

第 7 页的箱线图和雷达图是 PNG，**不随切片器、交叉筛选变化**。汇报时如果被问到"只看 2018 年"或"只看某个州"，这两张图会给出错误印象。

原生替代方案：

- 箱线图：Power BI 原生没有箱线图，要用 **R/Python 视觉对象**（环境里已有 anaconda），或者在模型里预计算 P25/P50/P75 用"高低线图 + 误差线"模拟；
- 雷达图：用 AppSource 的 **Radar Chart** 自定义视觉对象，或用 `pivotTable` + 条件格式做近似。

短期至少要在图题上写明"静态图，不随筛选变化"——现在标题里已经有"（静态图）"字样，这点做得对。

### 3.2 Cohort 矩阵：能显示，却不是热力图（优先级：高）

第 8 页实际渲染（截图 `data/v2_page_08.png`）：

- 行标签是**完整日期**：`2017年1月1日`、`2017年2月1日`……，不是月份；
- 列是 `4 5 6 … 16`，缺 0–3，也没有"距首购月数"的说明；
- 单元格值几乎全是 `0.00`、偶尔 `0.01`——比率被当小数显示，0.6% 变成 0.01，等于没信息；
- 色阶背景**没有生效**，只有默认的行间灰白条纹。

原因有两层：

1. `Values = Sum(cohort_retention_zh.留存率)`，比率求和没有业务含义，应改成 `Avg`；
2. 条件格式属性名写的是 `backColorPrimary`，矩阵取值正确的属性是 `backColor`，所以那套色阶被忽略。

修法：`Avg` + 数值格式 `0.0%` + `backColor` 色阶，或者直接在界面里用"条件格式 → 背景色 → 渐变"。

### 3.3 第 5 页多了一个自动标题的散点（优先级：中）

页面上除了地图，右侧还有一个 `scatterChart`（截图 `data/v2_page_05.png`）：

- 标题是 Power BI 自动生成的"客户经度的总和 和 客户纬度的总和"；
- `Category = state_kpis_zh.商品GMV`（拿数值列当分类轴，明显拖错了）；
- `X = Sum(客户经度)`、`Y = Sum(客户纬度)`，把经纬度求和当坐标，画出来的点没有地理意义。

它大概率是排查地图报错时留下的临时对象。建议删除，或者改造成"州级 GMV vs 迟到率"的散点并补标题。

另外地图本身 `X = Avg(客户经度)`、`Y = 客户纬度`（**原始列，没聚合**），两者口径不一致，正是之前"删除位置可显示经纬度 / 将经纬度聚合设为平均"提示的来源。现在能显示，说明 Power BI 走了按"州"定位的路径；建议把 Y 也改成 `Avg`，或直接删掉 X/Y 只保留"州"作为位置。

### 3.4 全报表没有切片器（优先级：中）

9 页、11 个视觉对象，**没有一个切片器**，也没有日期区间控件。这意味着：

- 看板无法按时间、品类、州、支付方式做统一筛选；
- 交叉筛选只能靠点击图形，粒度不可控；
- 作为"看板"交付时，使用方第一反应通常是"能不能选月份"。

建议至少加三个：日期（`日期表[Date]` 区间）、品类、州，放在每页顶部或做一个总览页统一放置。

### 3.5 标题写死了结论（优先级：中低）

图 2 标题"品类GMV Top 10：美妆个护第一"、图 6 标题"送达天数分布：集中在 8-15 天"、图 3 标题"信用卡约 78.5%"——这些数字是当前数据算出来的。一旦数据刷新（比如换到 2018 年底），标题和图形会不一致。

建议把结论性文字移到文本框（可单独维护），图题只写"品类 GMV Top 10""送达天数分布"这类中性描述。

### 3.6 其他

- 页面统一 1920×1080 `FitToPage`，没有移动端布局（Power BI 手机视图需要单独排）；
- 没有 KPI 卡片页（97,905 单 / GMV R$13.45M / AOV 160.19 / 复购 3.0% / 评分 4.12 / 迟到 8.13% 这些核心数字目前只在图里体现）；
- 没有页码、导航按钮或书签，9 页只能靠底部标签切换。
